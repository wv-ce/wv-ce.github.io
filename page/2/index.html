作业 1 什么是多道程序设计？多道程序设计与分时系统的区别是什么？ 多道程序设计：指在内存中同时存放多道作业，使它们共享 CPU 和外部设备。当一道程序因等待 I/O 而暂停执行时，CPU 立即转去执行另一道程序，从而提高资源利用率和系统吞吐量。 主要区别： 目标不同： 多道程序设计的主要目标是提高 CPU 利用率；分时系统的目标是提高人机交互性，使用户感觉自己独占计算机。 调度方式： 多道程序设计通常在程序遇到 I/O 阻塞时才切换；分时系统引入了时间片概念，强制程序在规定时间内轮流使用 CPU。 什么原因推动了操作系统从批处理发展到多道程序，进而发展到分时系统？ 批处理 →\rightarrow→ 多道程序： 主要是为了解决 CPU 与 I/O 设备速度不匹配的问题。单道批处理中 CPU 经常处于等待 I/O 的闲置状态，多道程序通过“交替执行”大幅提升了硬件利用率。 多道程序 →\rightarrow→ 分时系统： 主要是为了满足用户交互的需求。多道程序系统下，用户无法在程序运行期间进行干预，调试困难；分时系统通过快速切换，提供了实时响应能力。 什...
