BUAA CO 时序逻辑 理论笔记

时序逻辑

锁存器和触发器

触发器（基础概念，不重要）

触发器（Flip-Flop，FF）就是构成记忆功能部件的基本单元，或者说是实现存储（记忆）功能的基本单元电路。 触发器特点：

  1. 有两个互非的输出 QQQ 和 Q‾\overline{Q}Q​，QQQ 称为状态变量
    当 Q=0Q = 0Q=0（Q‾=1\overline{Q} = 1Q​=1）时称为 0 态，
    当 Q=1Q = 1Q=1（Q‾=0\overline{Q} = 0Q​=0）时称为 1 态。
  2. 无外加信号时，触发器保持原有状态（原态）不变，n 级触发器可以记忆 n 位二进制信息的 2n2^n2n 种状态。
  3. 在外加信号作用（触发）时，可以改变原态（具有置 0 或置 1 功能）。
    QnQ^nQn（原态）→ Qn+1Q^{n+1}Qn+1（次态）

钟控RS锁存器：加 CP 信号

D锁存器

将RS 锁存器的 R 端变为 S 端接非门，S 端接 D 端 S、R总是互非，钟控D锁存器不会出现不定状态

D触发器

一个D触发器可由两个反相的D锁存器构成，一主一从，时钟反相。

可添加：

  1. 使能端 EN：当 EN = 0 时，触发器不工作，保持原态。
  2. 复位端 R：当 R = 0 时，触发器输出 Q=0Q = 0Q=0，Q‾=1\overline{Q} = 1Q​=1。

寄存器由共享时钟信号CLK的多个D触发器构成，详见下文数据寄存器和数据锁存器

JK触发器

把R=1R=1R=1,S=1S=1S=1变为翻转（计数）功能 计数功能详见计数器

特性表（真值表）：

0 0 原态

特性方程：Qn+1=JQn‾+K‾QnQ^{n+1} = J \overline{Q^n} + \overline{K} Q^nQn+1=JQn​+KQn

有限状态机

有限状态机（Finite State Machine，FSM）：可描述有限个状态以及这些状态之间的转移及引起转移的动作等的离散数学模型。

  1. Moore型：输出只与当前状态有关
  2. Mealy型：输出与当前状态和输入有关

状态编码问题

  1. 二进制编码：节省逻辑资源，但可能产生毛刺
  2. 格雷码编码（相邻位置只有一位不同）：节省逻辑资源，避免毛刺
  3. 独热码编码：逻辑资源消耗大，但是状态转换简单

时序逻辑设计与分析

数据寄存器和数据锁存器

数据寄存器

  • 由边沿触发的触发器（D触发器）组成。
  • 通常由同步时钟信号来控制，属于脉冲敏感型
  • 适于数据有效提前于控制信号（一般为时钟信号）有效、并要求同步操作的场合。

  1. 清除（复位） 当 $ \overline{R_D} = 0 ，，， Q_0Q_1Q_2Q_3 = 0000 $
  2. 置数（复位端无效时） 当CP上升沿到来时，$ Q_0Q_1Q_2Q_3 = D_0D_1D_2D_3 $

数据锁存器

  • 由电位触发的触发器（D锁存器）组成。
  • 一般由电平信号来控制，属于电平敏感型
  • 适于数据有效滞后于控制信号有效的场合
  1. 当输入控制信号（如时钟）为高电平时，门是打开的，输出信号等于输入信号；
  2. 当输入控制信号为低电平时，门是关闭的，输出端保持刚才输入的数据，即为锁存状态，而不管此时输入信号是否变化。

移位寄存器

移位寄存器：具有移位功能的寄存器。每来一个时钟脉冲，寄存器中数据就依次向左或向右移一位。

应用：计算机中经常需要用到移位操作，如：

  • 乘法运算中的右移、除法运算中的左移等
  • 数据输入输出方式中的串行并行转换等

分类：

  1. 左移移位寄存器
  2. 右移移位寄存器
  3. 双向移位寄存器
  4. 循环移位寄存器

计数器

计数器：可以统计输入脉冲个数的器件

计数器的用途

  • （脉冲）计数
  • 计时
  • 定时（定时器）
  • 分频
  • 产生节拍脉冲（顺序脉冲）和序列脉冲

计数器的分类（不重要）

  1. 时钟方式：根据计数器中触发器时钟端的连接方式，分为同步计数器、异步计数器
  2. 计数方式：二进制计数器，十进制计数器，M进制计数器
  3. 状态变化：根据计数器中的状态变化规律分为加法计数器、减法计数器、加/减法计数器

同步计数器

特点：

  1. 各触发器同时翻转
  2. 计数速度快
  3. 尖峰信号宽度比较小
  4. 电路复杂

同步十六进制加法计数器（也称同步二进制（模16）加法计数器） 特性方程： Q0n+1=Q0n‾Q_0^{n+1} = \overline{Q_0^n}Q0n+1​=Q0n​​ Q1n+1=Q1nQ0n‾+Q1n‾Q0nQ_1^{n+1} = Q_1^n \overline{Q_0^n} + \overline{Q_1^n} Q_0^nQ1n+1​=Q1n​Q0n​​+Q1n​​Q0n​ Q2n+1=Q2nQ1nQ0n‾+Q2n‾Q1nQ0nQ_2^{n+1} = Q_2^n \overline{Q_1^n Q_0^n} + \overline{Q_2^n} Q_1^n Q_0^nQ2n+1​=Q2n​Q1n​Q0n​​+Q2n​​Q1n​Q0n​ Q3n+1=Q3nQ2nQ1nQ0n‾+Q3n‾Q2nQ1nQ0nQ_3^{n+1} = Q_3^n \overline{Q_2^n Q_1^n Q_0^n} + \overline{Q_3^n} Q_2^n Q_1^n Q_0^nQ3n+1​=Q3n​Q2n​Q1n​Q0n​​+Q3n​​Q2n​Q1n​Q0n​

异步计数器

特点：

  1. 钟脉冲只作用于最低位，高位时钟信号往往是由低一位提供的，高位待低一位翻转后才能翻转
  2. 计数速度慢
  3. 译码器输出会出现尖峰脉冲（不懂）
  4. 电路简单

异步十六进制加法计数器（JK触发器版） 特性方程： Q0n+1=Q0n‾⋅CP↓Q_0^{n+1} = \overline{Q_0^n} \cdot CP↓Q0n+1​=Q0n​​⋅CP↓ Q1n+1=Q1n‾⋅Q0↓Q_1^{n+1} = \overline{Q_1^n} \cdot Q_0↓Q1n+1​=Q1n​​⋅Q0​↓ Q2n+1=Q2n‾⋅Q1↓Q_2^{n+1} = \overline{Q_2^n} \cdot Q_1↓Q2n+1​=Q2n​​⋅Q1​↓ Q3n+1=Q3n‾⋅Q2↓Q_3^{n+1} = \overline{Q_3^n} \cdot Q_2↓Q3n+1​=Q3n​​⋅Q2​↓

反馈复位法

原理：当计数器到规定的模值时，将计数器为1的输出送至反馈电路，产生置0信号，使计数器复位。

异步十进制加法计数器 RD‾=Q3Q1‾\overline{R_D} = \overline{Q_3 Q_1}RD​​=Q3​Q1​​ 此时1010状态称为过渡状态，只出现瞬间

改进：增加基本RS触发器，增加RD‾\overline{R_D}RD​​的作用时间

集成计数器

4位同步二进制加法计数器74161（异步清除）、74163（同步清除），同步十进制加法计数器74160（异步清除）、74162（同步清除）

实现任意进制计数器：反馈复位法或预制法

  1. 输出C预制法 预制数据=计数器模值−需要模值预制数据=计数器模值-需要模值预制数据=计数器模值−需要模值 到最大数时，输出C为1，反相传到LD‾\overline{LD}LD预制
  2. 输出Q预制法 计数到新模值-1时，将输出为1的信号乘后取反作为预制信号
  1. 反馈复位法（通常指异步复位） 现象：如果你要做一个 10 进制计数器（0-9），当计数器跳到 10 (101010101010) 的那一瞬间，门电路检测到 Q3Q1=1Q_3 Q_1=1Q3​Q1​=1，立即产生复位信号。 状态：数字 10 只是一个短暂的“毛刺”，肉眼不可见，计数器会立即跳回 0。 有效状态：0,1,2,3,4,5,6,7,8,90, 1, 2, 3, 4, 5, 6, 7, 8, 90,1,2,3,4,5,6,7,8,9（共10个）。
  2. 输出Q预置法（通常指同步预置，如 74LS161） 现象：同样做 10 进制。由于预置端（Load）通常是同步的，当你检测到 9 (100110011001) 时，给 Load 发信号。 状态：计数器会稳稳地停在 9，直到下一个时钟脉冲到来，它才会根据 Load 信号跳回预置的值（如 0）。 有效状态：0,1,2,3,4,5,6,7,8,90, 1, 2, 3, 4, 5, 6, 7, 8, 90,1,2,3,4,5,6,7,8,9。优点：没有毛刺，电路工作非常稳定。
