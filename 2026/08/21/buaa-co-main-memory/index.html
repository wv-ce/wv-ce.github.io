BUAA CO 主存储器 理论笔记

主存储器

存储系统概述

存取时间：对RAM来说，是从给定地址到存储器完成读或写操作所需时间。对其他（如Cache）而言，则是指将读写机构定位到目标位置所需的时间。 存取周期：仅对RAM而言，指两次访问存储单元间的最小时间间隔。

存储器带宽是指存储器在单位时间内能够传输的数据量。

存储单元电路

存储单元电路

存储器中用来存储一位二进制信息（0或1）的电路，是组成存储器的基础和核心，也称存储元件、存储基元、存储位元、存储元。

基本要求

  • 具有两种稳定（或半稳定）状态，用来表示二进制的 0和1
  • 可以实现状态写入（或设置）
  • 可以实现状态读出（或感知）

存储器扩展

  1. 位扩展 原因

    • 芯片中存储字单元的数量够，即2n2^n2n够
    • 存储字单元的位数不够，即m不够

    方法

    • 多个存储器芯片的数据位空间拼在一起

    1. CS (Chip Select) —— 片选信号 CS 是 Chip Select 的缩写，中文通常称为片选信号。 作用： 用来选中（激活）某一个具体的存储芯片。 在图中： 你可以看到图（下面字扩展的图）中有 4 个 1Kx8 的存储芯片。为了构成一个更大的 4Kx8 存储器，系统必须知道当前是在访问哪一个芯片。 工作逻辑： 图中的 CS 上方有一横线 (CS‾\overline{CS}CS)，表示它是低电平有效。也就是说，当这个引脚输入为“0”（低电平）时，该芯片才会被选中并开始工作；如果为“1”（高电平），芯片则处于不工作（高阻）状态。
    1. WE (Write Enable) —— 写使能信号 WE 是 Write Enable 的缩写，中文称为写使能信号（或读写控制信号）。 作用： 用来控制是对芯片进行“读”操作还是“写”操作。 在图中： 所有的芯片都连接到了同一根 WE‾\overline{WE}WE 信号线上。 工作逻辑： 同样带有一横线 (WE‾\overline{WE}WE)，也是低电平有效。 WE‾=0\overline{WE} = 0WE=0 (低电平)： 执行写操作，将数据总线（Data Bus）上的数据写入被选中的存储单元。 WE‾=1\overline{WE} = 1WE=1 (高电平)： 执行读操作，将被选中存储单元中的数据输出到数据总线上。

  2. 字扩展 原因

    • 芯片中存储字单元的数量不够，即2n2^n2n不够
    • 存储字单元的位数够，即m够

    方法

    • 多个存储器芯片的字空间（地址空间）拼在一起

DRAM的刷新

DRAM刷新的特点

  • 刷新操作：读操作
  • 按行刷新、所有芯片同时进行
  • 刷新操作与CPU访问内存分开进行
  • 刷新周期：2ms, 4ms, 8ms
  • 刷新地址及刷新地址计数器

存储单元电路的刷新（不懂）

存储器芯片的刷新（不懂）

刷新方式

  1. 集中刷新 将刷新周期分成两部分：在一个时间段内，刷新存储器所有行，此时CPU停止访问内存；另一个时间段内，CPU可以访问内存，刷新电路不工作。 集中刷新间隔 = 刷新周期 优缺点：存在不能进行读写操作的死区时间（例64us），很少使用
  2. 分散刷新 CPU与刷新电路交替访问内存，一个存储周期刷新1行，下一个存储周期刷新另一行，直至最后1行后，又开始刷新第1行。 同1行两次被刷新的时间间隔可能小于刷新周期。 分散刷新间隔 = 刷新行数 X 存储周期 <= 刷新周期 优缺点：分散式刷新使系统速度降低，但不存在停止读写操作的死时间
  3. 分布式（异步）刷新方式 保证在一个刷新周期内将存储芯片内的所有行刷新一遍，可能等时间间距，也可能不等。 异步刷新间隔 = 刷新周期 优缺点：是前两种方式的结合，可减少死时间，同时保证性能
