欢迎来到我的个人网站

发表于2026-08-05|更新于2026-08-05
|浏览量:

大家好，我是 wv-ce。经过一番折腾，我的个人网站终于上线了 🎉。这篇文章就来聊聊这个网站的由来，以及我打算在这里写些什么。

为什么建这个网站

一直想有一个属于自己的地方，可以自由地记录、分享和思考。社交媒体虽然方便，但内容和形式都受限于平台。而一个自己的网站，从设计到内容都由自己掌控，这种感觉很好。

网站的技术方案

这个网站使用 Hexo 构建，主题为 Fluid。好处是：

  • 支持 Markdown 写作，专注内容本身
  • 明暗模式自动切换
  • 页面加载快，部署在 GitHub Pages 上

我会写些什么

  1. 技术笔记：把踩过的坑和学习心得记录下来
  2. 项目分享：介绍我做过的有意思的项目
  3. 生活随笔：一些日常的思考与记录

最后

网站刚刚起步，内容会慢慢丰富起来。如果你有什么建议，欢迎通过 GitHub 找到我。期待与你交流。
