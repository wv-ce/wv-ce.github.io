大家好，我是 wv-ce。经过一番折腾，我的个人网站终于上线了 🎉。
这篇文章就来聊聊这个网站的由来，以及我打算在这里写些什么。

## 为什么建这个网站

一直想有一个属于自己的地方，可以自由地记录、分享和思考。社交媒体
虽然方便，但内容和形式都受限于平台。而一个自己的网站，从设计到内容
都由自己掌控，这种感觉很好。

## 网站的技术方案

这个网站搭建在 GitHub Pages 上，使用纯 HTML / CSS / JavaScript 构建，
没有任何框架和构建工具。好处是：

- 零依赖，几乎不会过时
- 加载速度快
- 维护简单，一个仓库搞定

### 支持的明暗模式

网站支持明暗两种主题，可以通过右上角的按钮切换，选择会被记住。
也可以跟随系统的配色自动切换。

## 我会写些什么

1. 技术笔记：把踩过的坑和学习心得记录下来
2. 项目分享：介绍我做过的有意思的项目
3. 生活随笔：一些日常的思考与记录

## 写博客的流程

现在写一篇新博客非常简单：

1. 运行 `./new-post.sh "文章标题" "标签1,标签2"` 自动生成文件
2. 用 Markdown 写正文
3. 提交并推送，即可发布

| 步骤 | 操作 | 耗时 |
| ---- | ---- | ---- |
| 1    | 运行脚本生成草稿 | 1 秒 |
| 2    | 写 Markdown 正文 | 看心情 |
| 3    | git push 发布 | 1 分钟 |
