欢迎来到我的个人网站

2024-01-01 · 随笔 · 5 分钟阅读

大家好，我是 wv-ce。经过一番折腾，我的个人网站终于上线了 🎉。 这篇文章就来聊聊这个网站的由来，以及我打算在这里写些什么。

为什么建这个网站

一直想有一个属于自己的地方，可以自由地记录、分享和思考。社交媒体 虽然方便，但内容和形式都受限于平台。而一个自己的网站，从设计到内容 都由自己掌控，这种感觉很好。

网站的技术方案

这个网站搭建在 GitHub Pages 上，使用纯 HTML / CSS / JavaScript 构建， 没有任何框架和构建工具。好处是：

  • 零依赖，几乎不会过时
  • 加载速度快
  • 维护简单，一个仓库搞定

支持的明暗模式

网站支持明暗两种主题，可以通过右上角的按钮切换，选择会被记住。 也可以跟随系统的配色自动切换。

我会写些什么

  1. 技术笔记：把踩过的坑和学习心得记录下来
  2. 项目分享：介绍我做过的有意思的项目
  3. 生活随笔：一些日常的思考与记录

最后

网站刚刚起步，内容会慢慢丰富起来。如果你有什么建议，欢迎通过 GitHub 找到我。期待与你交流。
